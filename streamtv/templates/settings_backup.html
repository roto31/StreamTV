How it works

        
    
            
  • StreamTV writes streamtv-backup-latest.zip automatically after settings, channel, or schedule changes (30s debounce).
    • 
            
  • On a new Mac: download the latest zip, then Restore — or use the macOS app’s first-launch Restore.
    • 
            
  • Restore stages the zip and requires a server restart to apply (avoids mid-tune file swaps).
    • 
            
  • Machine-local FFmpeg/cache paths are not applied on restore.
    • 
        

        

            Operator guide: docs → Backup & Restore, or
            docs/guides/BACKUP_RESTORE.md.
