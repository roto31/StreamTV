# Core operator quickstart

1. **Dashboard** (`/`) — verify YouTube, Archive.org, PBS auth tiles are green.
2. **Build** — [Channel Builder](/builder) for URL-first channels, or [Import](/import) for YAML migration.
3. **Channels** (`/channels`) — enable channel, playout reset if needed.
4. **Tune** — Player (`/player`) or HDHomeRun (`/hdhomerun/discover.json`).
5. **Guide** — `/iptv/xmltv.xml` or merged `/tuners/guide.xml` when configured.

Docs: [Import vs Builder](/docs/import_vs_builder) · [HDHomeRun](/docs/hdhomerun)
