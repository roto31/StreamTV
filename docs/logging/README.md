## 📁 Log Location

All logs stored in: **`~/Library/Logs/StreamTV/`**

---

## 🛠️ Quick Commands

```bash
# View live logs
./scripts/view-logs.sh

# Search for errors
./scripts/view-logs.sh search ERROR

# Open log folder
open ~/Library/Logs/StreamTV/

# Test logging system
./scripts/test_logging.py
```
